# Blooket Bot Website

A functional website with text transformation tools and Blooket utilities.

## Features

✨ **Text Transformers**
- 🔄 Flip Text - Rotate text 180 degrees
- 🪞 Mirror Text - Mirror text horizontally
- 👻 Creepify - Add spooky diacritical marks
- 🤏 Tiny Caps - Convert to tiny capital letters

🎮 **Game Tools**
- Enter Game ID and Player Name
- (Note: Actual game joining requires backend API integration)

## Live Demo

Visit: https://thebringerofortune.github.io/BlooketBOT-Website/

## Files

- `index.html` - Main website with all UI and functionality
- `lunicode.js` - Text transformation library
- `README.md` - This file

## How to Use

1. Enter text in the "Text to Transform" field
2. Click one of the transformation buttons
3. See your transformed text appear below

## Technology Stack

- HTML5
- CSS3 (with gradients and animations)
- Vanilla JavaScript
- Lunicode.js library for text transformations

## Deployment

This site is hosted on GitHub Pages. To deploy your own:

1. Fork this repository
2. Go to Settings → Pages
3. Select `main` branch as source
4. Your site will be live at `https://yourusername.github.io/BlooketBOT-Website/`

## Limitations

- Text transformations work client-side ✅
- Blooket API integration requires a backend server (blocked by CORS) ❌
- Game joining/manipulation not possible from static GitHub Pages ❌
